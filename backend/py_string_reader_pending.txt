# `tokenize.STRING` token: it is FSTRING_START / FSTRING_MIDDLE / FSTRING_END with the
# interpolations tokenised between them. A harness that walks STRING tokens and knows nothing of
# that shape therefore STOPS SEEING f-strings on 3.12+ — and the dangerous direction is not red,
# it is QUIET: it keeps passing while reading past the thing it was written to catch.
#
