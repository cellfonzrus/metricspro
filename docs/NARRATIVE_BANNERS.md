# Narrative banners

A **narrative banner** is a plain-English summary rendered above a report — e.g.
_"Activations are running 11% ahead of last month — 1,204 vs 1,086 through the 27th. Diversey leads the gain (+18), driven by ports. Accessory sales $48,900 (6% up vs last month), $41.20 per box."_

## Principle: deterministic, not LLM prose

Every sentence is **computed from the exact same numbers the report shows** — it is not generated by a language model. This is deliberate:

- It can never contradict the grid it sits above (same aggregation, same filters).
- It needs no API key and adds no dependency.
- It cannot hallucinate a figure — a reconciliation report's whole value is that its numbers are trusted.

## How it works

**Backend** (`commcalc/router.py`):

- `_narrate`/comparison helpers — `_pct_change`, `_dir_word` (returns the phrase + a good/bad `tone`), `_ordinal`.
- Per-report builder — e.g. `_mtd_narrative(client, org_id, period, today, stores, markets, reps)`. It gathers the **current** and **prior** facts over a fair window and returns `{ available, comparative, tone, headline, bullets[], facts{} }`.
  - **Fair comparison window**: an *open* month compares month-to-date (day 1 → yesterday, complete days only) against the **same day window** of last month; a *closed* month compares the whole month vs the whole prior month. Both windows are fed to the same `_exec_mtd` aggregation the table uses.
  - `tone` is `up` / `down` / `flat`, keyed to whether the movement is *good* for the metric (so a fall in chargebacks is green, a fall in activations is red).
  - Never raises — any failure returns `{ available: false }` and the banner simply doesn't render.
- Endpoint — `GET /exec-mtd/{period}/narrative`, honoring the same `stores` / `markets` / `reps` filters as the report.

**Frontend** (`components/NarrativeBanner.tsx`):

- `<NarrativeBanner url={narrativeUrl} />` — fetches the endpoint, renders the headline + bullets with a tone-keyed accent, and renders **nothing** until the endpoint says `available`.
- The host page builds `narrativeUrl` from the same filters it sends to the report, and passes `null` to hide the banner when a comparison wouldn't be apples-to-apples (e.g. a custom date-range slice on the MTD report).

## Adding a banner to another report

1. Backend: write `_<report>_narrative(...)` that collects the current + prior totals and returns the `{ available, tone, headline, bullets, facts }` shape (reuse `_pct_change` / `_dir_word` / `_ordinal`). Expose it as `GET /<report>/{…}/narrative`.
2. Frontend: build the narrative URL from the page's filters and drop `<NarrativeBanner url={...} />` above the grid.

First shipped on: **Executive MTD** (`/commcalc/exec/mtd`).
